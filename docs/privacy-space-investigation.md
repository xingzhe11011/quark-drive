# 隐私空间接口调查与实现

更新时间：2026-11-12

## 当前状态

客户端已接入隐私空间，并已由真实账号确认密码解锁与目录读取：

- 使用现有普通账号会话检查是否已设置隐私空间。
- 用户在独立页面输入夸克隐私密码后，客户端调用隐私解锁接口。
- 解锁成功后可按页浏览隐私根目录和子目录，支持面包屑和手动刷新。
- 支持隐私文件和多级文件夹下载、上传，以及文件/文件夹移动。
- 手动锁定、离开页面、切换账号、退出登录或退出软件都会撤销内存中的隐私会话。
- 隐私目录只显示在当前页面内存中，不进入普通文件缓存、SQLite、传输记录、设置或 bootstrap。
- 隐私上传/下载任务只存在于当前解锁会话的内存中；锁定或离开页面会取消任务并清除敏感元数据。
- 暂不支持隐私删除、回收站、搜索和分享操作。

真实账号已确认隐私密码解锁、隐私根目录和子目录读取。上传、下载、移动由协议模拟测试覆盖，仍需在真实账号上执行最终写入验收。

## 为什么不能直接读取 FID 2

普通登录会话直接请求 `pdir_fid=2` 时，夸克服务端在 `drive.quark.cn` 和 `drive-pc.quark.cn` 都返回：

```text
HTTP 403
code 24005
message secret space limit: get file vo
```

同一会话读取普通根目录 `pdir_fid=0` 正常。把 `2` 当普通目录、清空缓存或静默重试都不能解决；必须先取得隐私空间令牌，并在隐私请求中携带专用请求头。

## 已确认的解锁协议

### 请求

```http
POST https://drive-m.quark.cn/1/clouddrive/secret/v2/login
Content-Type: application/json
```

```json
{"secret_pwd":"用户输入的隐私密码"}
```

观察结果来自官方 Android 网盘客户端 `com.quark.clouddrive` 版本 `10.20.5.142`（APK SHA-256 `ba80a14548c29b2e2f6c5ebafe0ceb64e0b84d973c047daae7af207a124e1529`）：

- 密码字段为 `secret_pwd`。
- 字段值是用户输入的明文密码，没有观察到客户端哈希、加盐或额外签名。
- 请求由 Flutter 的 `libunet_plugin.so` 发送，不是 Java HTTP。
- 本软件只使用独立 HTTPS 请求，不修改官方客户端，也不读取或复用官方客户端文件。

### 成功响应

```json
{
  "status": 200,
  "code": 0,
  "data": {
    "succ": true,
    "token": "隐私空间令牌"
  }
}
```

客户端严格校验：

- `data` 必须是对象。
- `data.succ` 必须是布尔值 `true`；字符串、数字和其他真值都拒绝。
- `data.token` 必须是非空字符串，并可作为 HTTP 头值。

`succ` 和 `token` 的字段名来自官方 AOT 代码的精确对象池读取和成功响应解析函数的静态交叉验证，不是根据相邻字符串猜测。使用仅含合成密码和合成令牌的本地响应时，官方客户端显示解锁成功，并通过 Java 桥接收到合成令牌。

### 隐私列表请求

隐私目录继续使用：

```http
GET /1/clouddrive/file/sort?pr=ucpro&fr=pc&pdir_fid=...&_page=...&_size=...
```

专用请求头名称为 `X-U-Drive-Secret-Auth`，值为 `data.token`：

```http
X-U-Drive-Secret-Auth: <data.token>
```

官方 Dart 拦截器直接写入令牌值，不添加 `Bearer`、前缀或额外哈希。普通 API 请求不携带该头，CDN Range 下载请求也不携带该头。

当前实现发送 `name_space=0`，与官方通用列表包装器的默认值一致。官方代码中存在其他 `name_space` 取值，但已定位的显式非零调用点属于音频备份，不能据此推断隐私空间。若真实读取返回 `24005`，应先排查该参数、隐私根 FID 和令牌作用域，而不是把错误当成密码错误。

## 隐私移动与传输

隐私移动使用专用接口：

```http
POST /1/clouddrive/secret/file/move
X-U-Drive-Secret-Auth: <data.token>
```

```json
{
  "action_type": 1,
  "exclude_fids": [],
  "filelist": ["<fid>"],
  "to_pdir_fid": "<目标目录 FID>"
}
```

没有发现独立的隐私上传或下载元数据接口，因此复用普通接口，并在以下请求上附加隐私令牌：

- `POST /file/download`
- `POST /file/upload/pre`
- `POST /file/update/hash`
- `POST /file/upload/auth`
- `POST /file/upload/finish`

隐私文件名冲突检查、目录创建、递归列目录和下载直链刷新都通过隐私列表接口完成，不读写普通文件缓存。OSS 分片 `PUT`、OSS 合并 `POST` 和 CDN Range 下载只使用签名参数、Cookie 与 OSS 授权头，不携带隐私令牌请求头。

隐私上传/下载任务不写 SQLite。任务队列、文件名、FID、路径和取消令牌仅保存在进程内存；锁定、注销、重新登录、重叠解锁或离开隐私页会让旧 epoch 失效并取消任务。前端在锁定时收到脱敏的取消事件。

## 安全设计

- 隐私密码只存在于单次解锁调用和请求体中；前端提交后立即清空输入框，不写入日志、状态历史、SQLite、凭据文件或事件。
- 隐私令牌只存在协议层内存对象中，不序列化、不持久化、不向前端返回。
- 隐私元数据 API 使用独立 `reqwest::Client`，禁止跟随重定向；CDN/OSS 使用不携带隐私令牌的传输客户端。
- 隐私请求只在显式解锁后、账号匹配且会话未撤销时构造。
- 核心层为每个账号维护独立的 epoch 和取消令牌。锁定、注销、重新登录或重叠解锁都会使旧请求失效，迟到响应不能重新安装令牌或恢复列表。
- 隐私目录不使用普通 `file/sort` 缓存路径，不写 SQLite 文件缓存。
- 隐私列表读取失败时默认失效并锁定，前端清除已显示名称，避免继续展示不确定的敏感结果。
- 隐私上传/下载不写 SQLite 传输记录；锁定或离开页面时取消任务，并将前端已有的任务名称替换为脱敏占位文本。
- CDN 和 OSS 请求从不包含 `X-U-Drive-Secret-Auth`。
- 关闭软件后令牌自然丢失；重新启动后普通账号仍可恢复登录，但隐私空间必须重新解锁。

## 自动验收

### 协议与核心

- 验证解锁请求的精确 JSON 字段、Cookie、Origin、Referer 和无隐私头。
- 验证隐私列表的专用头、分页查询参数和专用主机。
- 验证缺失、非布尔、非字符串、空令牌和畸形响应全部拒绝。
- 验证错误响应和重定向不泄露密码或令牌，且重定向目标收不到请求。
- 验证共享令牌的所有克隆在锁定后立即失效。
- 验证锁定、注销、重叠解锁、账号切换和迟到列表响应。
- 验证隐私列表不写普通缓存，隐私令牌、密码和文件名不进入数据目录或事件。
- 验证重启后隐私会话保持锁定。
- 验证隐私移动的精确路径、请求头和 JSON 请求体。
- 验证隐私下载/上传元数据请求携带令牌，而 CDN Range 和 OSS 分片/合并请求不携带令牌。
- 验证隐私文件上传、下载、文件名冲突处理、移动，以及锁定后取消并脱敏正在运行的任务。

### 官方客户端运行观察

在 Android 13 本地研究环境中运行未登录的官方客户端，并仅将网络层重定向到本机合成服务。使用合成密码和合成令牌，未使用真实账号或真实隐私密码：

- 观察到唯一解锁请求路径和明文 `secret_pwd` 请求体。
- 修正本地传输桥后，完整 JSON 响应被 Dart 层读取。
- 仅有 `pass`、`success` 等字段时官方客户端提示“密码验证失败”。
- 改为 `data.succ=true` 和 `data.token` 后，官方客户端接受响应，令牌桥事件确认收到合成令牌。

这项运行观察验证的是协议契约，不证明真实服务端成功，也不替代真实账号验收。

## 真实账号验收步骤

1. 启动 `target/debug/quark-drive`，使用普通扫码登录进入自己的账号。
2. 打开左侧“隐私空间”，确认显示已设置隐私密码。
3. 在软件自己的密码框中输入隐私密码；不要把密码、Cookie 或令牌发到聊天、Issue 或日志。
4. 确认能读取隐私根目录并进入子目录、翻页。
5. 上传一个小文件，确认传输完成且网页端/官方客户端能看到文件。
6. 下载一个隐私文件，确认大小和内容一致；再验证多级文件夹下载。
7. 勾选文件或文件夹并执行“移动”，确认目标和内容正确。
8. 执行“立即锁定”，确认列表立即清空、运行中的隐私任务被取消；再次访问必须重新输入密码。
9. 切换到其他普通目录，确认普通请求没有隐私头且功能不受影响。
10. 退出软件并重新打开，确认普通账号仍登录、隐私空间仍锁定。

上传、下载、移动如失败，请保留不含账号数据的错误码、操作类型和请求路径。不要把 Cookie、隐私密码、令牌或真实隐私文件名发到 Issue。

若第 4 步失败，保留不含账号数据的错误码和请求路径，重点检查 `name_space`、隐私根 FID、服务端错误码和真实令牌响应。
